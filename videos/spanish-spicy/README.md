# Reel: „Spanish Curse Words They Don't Teach You in School“ 🌶️

Kinder-Zeichentrick-Stil, aber Inhalt für Erwachsene (1080×1920, 30 fps, 43,5 s).
Format pro Wort (4,5 s): **Situation** („You stub your toe…“) → Coco wird wütend → **spanisches Fluchwort knallt rein**
→ Aussprache → Region (Spanien / Lateinamerika / überall) → Schärfe 🌶️–🌶️🌶️🌶️ → englische Übersetzung.

Die englischen Flüche sind im Bild mit Sternchen verdeckt („Sh*t!“) und werden im Ton überpiept.
Das spanische Wort ist voll zu sehen und zu hören, denn darum geht es beim Lernen.

| Wort | Englisch | Wo | Situation |
|---|---|---|---|
| ¡Mierda! | Sh*t! | überall | Zeh gestoßen |
| ¡Joder! | F*ck! | Spanien | Handy fällt runter |
| ¡Hostia! | Holy sh*t! | Spanien | Rechnung sehen |
| ¡Carajo! | Damn! | Lateinamerika | Bus verpasst |
| ¡Maldita sea! | Damn it! | überall | Toast verbrannt |
| Gilipollas | Dumb*ss | Spanien | Vordrängler |
| Pendejo | Idiot | Lateinamerika | Auto spritzt dich nass |
| Cabrón | B*stard (in Mexiko auch „dude“) | überall | Freund isst deine Pommes |

```bash
node render.mjs && python3 audio.py                 # Bild + Musik/Effekte
python3 ../voice_mix.py spanish-spicy               # Stimmen (Kokoro) + Piep -> out/spanish-spicy-stimme.mp4
```
